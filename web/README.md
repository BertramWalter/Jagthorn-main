# Jagthorn – frontend (React + TypeScript + Vite)

Dette er frontend-delen af Jagthorn-appen. Se den fulde dokumentation i
projektets [rod-README](../README.md) for formål, installation, kommandoer,
hvordan man tilføjer melodier, Aspire-opstart og licens.

## Hurtig start

```bash
npm install
npm run dev
```

## Nyttige kommandoer

- `npm run dev` – udviklingsserver
- `npm run build` – produktionsbuild til `dist/`
- `npm test` – kør tests
- `npm run lint` – lint
- `npm run typecheck` – typecheck
- `npm run generate:catalog` – regenerér melodikataloget fra `public/`-assets
